### Validation and limitations

Validation completed on November 11:

- All 13 added titles and first-submission dates match the retrieved abstract metadata and v1 histories. All 12 closer screened candidates’ titles and dates were checked as well; the README and source-table titles, dates, and categories agree.
- The 113 existing paper identities, dates, titles, and categories are unchanged. The project table contains six distinct resources ordered newest-checked first, matching both advertised project counts.
- All **76 distinct newly linked external destinations** across README and SOURCES returned HTTP 200 with nonempty responses. Author linkage and source contents were checked separately; HTTP success alone does not establish provenance, completeness, or scientific validity. PDDL-ART’s unavailable prompt collection was not added as a resource link.
- `python3 scripts/check_readme.py` passed for **126 unique papers**, checking dates, ordering, counts, anchors, and local links. `git diff --check` passed.
- The complete README and SOURCES diff was reviewed for scope, original summaries, duplicate handling, first-submission dates, resource labels, and internal consistency. Only those two documentation files were changed; new entries use backslash hard breaks without trailing whitespace.

This is a selective literature search and source inspection, not experimental reproduction. API rate limits, empty general-web results, overlapping query windows, incomplete HTML conversion, unavailable resources, and morning-only coverage constrain discovery. No research code, generated worlds, model weights, or robot experiments were executed. Historical search and release observations above remain unchanged; only specifically checked current resources have updated status.

- The destination was supplied by the paper or an author-controlled project page.

## Date caveat

[World-Time Compute with Verified Code World Models](https://arxiv.org/abs/2609.09163) reports **July 7, 2026** in its v1 submission history and citation metadata even though its identifier begins with `2609`. This list preserves the reported submission date and flags the discrepancy rather than silently changing it.

Similarly, TheoryCoder-2 reports January 31, 2026 despite a `2602` identifier. Identifiers should not be used as exact publication dates.
